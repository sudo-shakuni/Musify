# Contributing to Musify 🎵

Thank you for your interest in contributing to **Musify**! We welcome contributions from developers, designers, and music enthusiasts worldwide.

---

## How Can You Contribute?

1. **Reporting Bugs**:
   - Check existing issues before opening a new one.
   - Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md).
   - Provide reproduction steps and the Spotify link that triggered the error.

2. **Suggesting Features**:
   - Open a feature request to discuss ideas before writing large pull requests.

3. **Submitting Pull Requests (PRs)**:
   - Fork the repository and create a feature branch (`git checkout -b feature/awesome-feature`).
   - Keep changes focused and well-documented.
   - Run existing unit tests (`python test_suite.py`) before submitting.
   - Submit the PR against the `main` branch.

---

## Code of Conduct

- Be welcoming, respectful, and collaborative.
- Respect intellectual property and project goals.
- Keep discussions constructive and focused on software quality.

---
*Happy coding & happy listening!*
